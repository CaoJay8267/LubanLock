# Web research

1. Turn the question into two to five search queries with different wording.
2. Run `web_search`, then open the most promising results with `web_fetch`.
3. For every claim, record the URL and the exact sentence that supports it.
4. Cross-check each important claim in a second independent source.
5. Stop when new searches only repeat sources you already have.

Use [checklist.md](checklist.md) when you need the detailed review checklist.
