# Citation format

Use numbered citations in square brackets and a source list at the end:

```text
Finding text [1].

[1] Title — https://example.com/page (accessed 2026-01-01)
```

Rules:

- Cite the page that contains the claim, not a search-result page.
- Keep the access date in ISO 8601 form.
- If two sources disagree, present both and label the conflict.
